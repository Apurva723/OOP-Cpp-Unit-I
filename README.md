Brief description of each program

1 - Basic Data Types – Demonstrates the use of int, char, and float data types to store student details.

2 - if-else – Checks whether a student's marks are enough to pass or fail.

3 - Loop and Array – Stores the marks of five students in an array and displays them using a for loop.

4 - Functions – Demonstrates how to create and call a function to perform addition of two numbers.

5 - Class and Object – Demonstrates how a class and object can be used to store and display student details.

6 - Constructor and Destructor – Demonstrates the automatic execution of a constructor when an object is created and a destructor when it is destroyed.

7 - Static Member – Demonstrates how a static data member can be used to count the number of objects created.

8 - Inline and Friend Function – Demonstrates an inline function for accessing private data and a friend function for accessing private class members.
